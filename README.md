# marciowecker-site

Site profissional de Marcio Wecker. Vite + React 18 + TypeScript + Tailwind v4 + Three.js/R3F + GSAP + Lenis + Framer Motion.

## Desenvolvimento

```bash
npm install
npm run dev
```

Abre em `http://localhost:5173`.

## Scripts

- `npm run dev` — servidor de desenvolvimento
- `npm run build` — build de produção (`dist/`)
- `npm run preview` — serve o build localmente
- `npm run lint` — ESLint
